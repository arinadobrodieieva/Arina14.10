Анатомія розділу <head>

Контейнер <head> містить службову (технічну) інформацію про сторінку, яка не відображається безпосередньо у вікні браузера, але є критично важливою для пошукових систем, браузерів та коректного стилю сайту.

У коді цієї сторінки (всередині тегу head) ми використали такі елементи:

  • <meta charset="UTF-8"> — захищає текст від появи незрозумілих символів («ієрогліфів»).
  • <meta name="viewport"> — робить сторінку зручною для мобільних телефонів.
  • <title> — задає заголовок вкладки у вашому браузері.
  • <meta name="description"> — це короткий текст, який показує Google у результатах пошуку.
  • <link rel="icon"> — додає маленьку картинку (логотип) на вкладку сайту.
  • <style> — містить CSS-код для оформлення шрифтів, кольорів та блоків.

Щоб перевірити, як працюють ці теги, відкрийте цей файл у браузері та подивіться на назву та іконку вкладки, або натисніть клавіші Ctrl + U, щоб побачити весь прихований код сторінки.
